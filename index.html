02ХАРАКТЕР / PERFORMANCE

Мощность без шума.
Скорость без паузы.

Электромотор не требует раскрутки. Крутящий момент приходит сразу — без задержки, без переключений, без театра.

Вся архитектура R1 подчинена одной идее: меньше инерции, меньше лишнего, больше контроля в каждом миллиметре хода ручки.
