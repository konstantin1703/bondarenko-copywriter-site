# VANTA R1

VANTA R1 — вымышленный showcase-проект электрического superbike. Сайт собран как самостоятельная digital-презентация с фотографической art direction, крупной типографикой и интерактивным Ride System.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Cloudinary media delivery
- GitHub Pages

## Disclaimer
VANTA R1, бренд и технические характеристики являются частью демонстрационного концепта. Фотографии используются как визуальная постановка; авторы указаны в футере сайта.
