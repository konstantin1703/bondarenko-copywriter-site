# VANTA R1

VANTA R1 is a fictional electric performance motorcycle website built as an independent digital concept study.

## Stack

- Semantic HTML5
- Modern CSS (responsive layout, custom properties, motion, accessibility fallbacks)
- Vanilla JavaScript
- Inline SVG product illustration
- Canvas signal-field rendering
- GitHub Pages

The project intentionally has zero runtime dependencies and no build step.

## Structure

- `index.html` — page structure and product illustration
- `styles.css` — visual system, layout, responsive behavior and motion
- `app.js` — interactions, telemetry modes, finish configurator, canvas renderer
- `404.html` — branded error page
- `favicon.svg` — vector favicon
- `site.webmanifest`, `robots.txt`, `sitemap.xml` — web metadata

## Notes

VANTA and R1 are fictional. All specifications are concept-study targets and are not claims about a real product.
